## Overview

Codex is an AI-assisted engineering knowledge system for keeping project documentation, procedures, tradeoffs, and decisions retrievable as systems grow. It is not framed as generic AI hype. It is infrastructure for engineering memory.

The project supports the Loose Arrow Labs operating model: authored notes remain the source of truth, while retrieval and local AI workflows help surface the right context during design, debugging, and documentation.

## Engineering Problem

As technical projects multiply, the cost of lost context rises:

- Decisions need to remain connected to the constraints that produced them
- Procedures should be easy to find during maintenance or debugging
- Known questions should retrieve known documents reliably
- AI assistance should improve workflow without replacing authored source material
- Documentation should be treated as a system with regression checks, not a pile of notes

## Architecture Direction

- Markdown and repo-content ingestion
- Full-text search and vector retrieval where useful
- Query interface organized around engineering workflows: procedures, ADRs, troubleshooting notes, and project context
- Local AI tooling for guided assistance with visible source material
- Retrieval-quality checks for known questions and expected documents

## Current Status

- Retrieval flow and service structure are being iterated
- Prompting and document structure are being tuned around engineering use cases
- Documentation templates and operating procedures are being standardized
