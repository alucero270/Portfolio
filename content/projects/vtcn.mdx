## Overview

VTCN is an embedded Linux telemetry platform built around the BeagleBone Black. The project exists to make device-side engineering visible: interface bring-up, sensor acquisition, framed telemetry, local buffering, network transport, service reliability, and validation notes.

It is the embedded proof surface for Loose Arrow Labs: a small system where hardware interfaces, Linux services, data contracts, and operating procedures have to work together.

## Engineering Problem

Telemetry systems are easy to describe and easy to make brittle. Useful telemetry needs more than a sensor read:

- Interfaces need bring-up and repeatable validation
- Data needs framing, timestamps, and integrity checks
- Offline behavior needs local persistence
- Network transport needs clear retry and failure behavior
- Services need logs, systemd configuration, and recovery behavior
- Development needs simulator paths when hardware is not connected

## Architecture Direction

- User-space C/C++ service for GPIO/I2C/SPI/UART interaction
- Framed telemetry records with timestamps and CRC/checksum behavior
- SQLite buffering for intermittent network availability
- TCP/UDP transport to a collector or dashboard
- Structured logs for diagnostics and operating notes
- Bring-up checklists for each hardware interface
